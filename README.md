# 2026-S1-13 Capstone Project

## Aphrodite’s Harvest & Learn About Bees

This repository contains the final capstone project deliverables for **Aphrodite’s Harvest** and **Learn About Bees**, completed by **Group S1-13** at Adelaide University in 2026.

The project focused on improving the client’s digital presence, website usability, course structure, social media consistency, SEO visibility, and long-term self-management capability.

## Project Purpose

Aphrodite’s Harvest already provides valuable beekeeping courses, support services, events, and honey-related products. However, the digital experience required clearer structure, stronger user guidance, and practical tools that the client could maintain independently.

The purpose of this project was to design a practical and sustainable digital improvement package that helps the client:

* Improve website usability and customer navigation
* Make Learn About Bees courses easier to understand and access
* Strengthen social media planning and consistency
* Improve basic SEO visibility
* Provide a self-management toolkit for future updates
* Support client independence without requiring a full website rebuild

## Key Deliverables

This repository includes the following project deliverables:

* Website user experience audit and recommendations
* SEO analysis and optimisation plan
* Social media strategy and content planning
* Educational Framework for Learn About Bees
* Prototype screens, wireframes, and interface improvement concepts
* Static HTML prototype/mockup
* Self-Management Toolkit
* Final presentation materials
* Individual contribution evidence from each team member

## Project Approach

The project followed a practical digital transformation approach. The team reviewed the current website and digital channels, identified key problems, designed improvement concepts, and prepared client-friendly recommendations.

The solution was designed to be:

* Practical for a small business
* Easy to understand
* Low-cost to implement
* Compatible with WordPress/WooCommerce where relevant
* Sustainable for the client to manage after handover

## Overall Project Value

The final solution helps Aphrodite’s Harvest and Learn About Bees create a clearer and more professional digital experience. It supports customers by making information easier to find, improving course discovery, and guiding users toward the right learning or support pathway.

For the client, the project provides practical tools and recommendations that can be maintained over time without heavy technical support.

## Important Note

Some deliverables in this repository are prototypes, mockups, or recommendation documents. They are intended to demonstrate design concepts, user flows, content structures, and implementation possibilities. They are not full backend systems or final live website deployments.
