# Figma Recommendation Design

## Purpose

This folder contains the Figma design files and exported screens created to visually present the Educational Framework recommendations.

The Figma design was created after analysing the existing Learn About Bees website and identifying improvement areas in the course journey, support service structure, events page, and enquiry pathway.

## How This Connects to the Educational Framework

The Educational Framework recommended a clearer learning journey for users. The Figma design translates those recommendations into visual interface screens.

The design supports:

* Four-level learning pathway: Beginner, Intermediate, Specialist, Advanced
* Clearer course discovery
* Better separation between Courses and Support Services
* Improved lesson viewing structure
* Clearer event and enquiry pathways
* Improved user guidance and website usability

## Included Files

* Original Figma design file
* Figma PDF export
* Course catalogue screen
* Lesson viewer screen
* Course completion screen
* Events screen
* Contact form screen
